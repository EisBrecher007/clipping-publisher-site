Privacy Policy

Website data

This static website does not provide accounts, forms, analytics, advertising trackers, or cookies set by Clipping Publisher. It does not ask visitors to submit personal information.

Publishing workflow data

The local project may retain campaign rules, authorized source references, video files, checksums, captions, scheduling data, and audit records needed to prepare a publishing job. This information is used only for that workflow.

TikTok authorization

If TikTok API integration is enabled in the future, authorization will use TikTok’s official OAuth flow. TikTok credentials are not requested or stored by this website. Any authorized API access will be used only for the account and publishing purpose approved by the account owner.

Sharing and retention

Clipping Publisher does not sell personal information. Information is not shared except where needed for an authorized API action or where required by law. Local workflow records are retained only as long as needed for operational, audit, or rights-compliance purposes.
